# Customer Shopping Behavior Analysis

An end-to-end data analysis project that cleans raw customer shopping data in Python, loads it into MySQL for SQL-based analysis, and visualizes the results in a Power BI dashboard.

## 🔄 Project Pipeline

```
customer_shopping_behavior.csv
        │
        ▼
customer_shopping_behaviour.ipynb   (clean & transform with pandas)
        │
        ▼
MySQL database (customer_behaviour.customer)
        │
        ▼
customer_shopping_behavior.sql      (business-question SQL queries)
        │
        ▼
Customer_behavoiur.pbix             (Power BI dashboard)
```

## 🗂️ Repository Contents

| File | Description |
|---|---|
| `customer_shopping_behavior.csv` | Raw source dataset (3,900 customer records) |
| `customer_shopping_behaviour.ipynb` | Data cleaning & transformation notebook (pandas) |
| `customer_shopping_behavior.sql` | SQL queries answering key business questions |
| `Customer_behavoiur.pbix` | Power BI dashboard for visual exploration |

## 📁 Dataset

The raw dataset contains the following fields (cleaned to lowercase/snake_case in the notebook):

| Column | Description |
|---|---|
| `customer_id` | Unique customer identifier |
| `age` | Customer age |
| `gender` | Customer gender |
| `item_purchased` | Product purchased |
| `category` | Product category |
| `purchase_amount` | Purchase amount (USD) |
| `location` | Customer location |
| `size`, `color`, `season` | Product attributes |
| `review_rating` | Product review rating |
| `subscription_status` | Whether the customer is subscribed |
| `shipping_type` | Standard / Express, etc. |
| `discount_applied` | Whether a discount was applied |
| `previous_purchases` | Number of previous purchases by the customer |
| `payment_method` | Payment method used |
| `frequency_of_purchases` | How often the customer purchases |

### Cleaning & feature engineering (notebook)

- Standardized column names (lowercase, underscores; e.g. `purchase_amount_(usd)` → `purchase_amount`)
- Filled missing `review_rating` values with the median rating per `category`
- Dropped the redundant `promo_code_used` column (identical to `discount_applied`)
- Bucketed customers into age groups (`group_age`): Young Adults, Adults, Middle Age, Senior (quartile-based)
- Converted `frequency_of_purchases` (e.g. "Weekly", "Annually") into an estimated numeric `frequency_day_purchase` (days between purchases)
- Loaded the cleaned data into a MySQL database (`customer_behaviour.customer`) via SQLAlchemy

## ❓ Business Questions Answered (SQL)

1. Total revenue generated by male vs. female customers
2. Customers who used a discount but still spent more than average
3. Top 5 products by highest average review rating
4. Average purchase amount: Standard vs. Express shipping
5. Do subscribers spend more? Average spend & total revenue, subscribers vs. non-subscribers
6. Top 5 products by highest percentage of discounted purchases
7. Customer segmentation (New / Returning / Loyal) by purchase history, with counts
8. Top 3 most purchased products within each category
9. Are repeat buyers (5+ previous purchases) more likely to subscribe?
10. Revenue contribution of each age group

## 📊 Power BI Dashboard

`Customer_behavoiur.pbix` visualizes the query results above — revenue by gender, category, age group, and shipping type; subscription and discount trends; and customer segmentation — for interactive exploration.

## 🚀 Getting Started

### Prerequisites

- Python 3.8+ with `pandas`, `seaborn`, `sqlalchemy`, `mysql-connector-python`
- MySQL Server
- Power BI Desktop (Windows) to open the `.pbix` file

### Installation

```bash
git clone <your-repo-url>
cd <your-repo-folder>
pip install pandas seaborn sqlalchemy mysql-connector-python
```

### Usage

1. **Clean the data**: Open `customer_shopping_behaviour.ipynb` and run all cells. Update the MySQL connection parameters (`USER`, `PASSWORD`, `HOST`, `PORT`, `DATABASE`) to match your local setup before running the database-loading cell.
2. **Run the analysis**: Execute the queries in `customer_shopping_behavior.sql` against your MySQL database to answer the business questions above.
3. **Explore the dashboard**: Open `Customer_behavoiur.pbix` in Power BI Desktop and refresh the data source to point at your MySQL instance.
